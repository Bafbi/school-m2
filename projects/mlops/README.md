# mlops — chatbot skeleton (unfinished)

What was built for the MLOps project before it was abandoned: a Streamlit chat
front-end (`frontend/main.py`) with session history and an echo backend, plus the
environment declaration (`mise.toml`, `pyproject.toml`, `uv.lock`).

Kept for completeness — it is a skeleton, not a working project. The assignment
brief was a separate PDF and is not committed here.
