# locchain — poster: French digital public infrastructure and sovereign cloud

A conference-style poster and its companion infographic, rendered as
self-contained HTML (inline SVG, no external assets).

```
poster.html             the poster
infographic.html        one-page summary
Generated Poster.jpeg   exported image, the form it was handed in
cards_icons/            the icon set used by both
output/                 render output directory
```

The subject: Digital Public Infrastructure as a strategic asset — governance,
architecture and long-term stability of French sovereign cloud, seen through the
SecNumCloud qualification, the 2026 sovereignty roadmap and the shift in digital
trust.
